# Relatório de Validação de PRD — PR2 Células

> Origem: discovery20260704_173116.md + stories-requisitos20260704_173116.md
> Código validado no repo (base commit `7b31d4c`, PR1 em main).
> Data: 2026-07-04.

## Problemas identificados

- **P1** [APLICADO] [Conflitos] RNF-13 cita "409/idempotência" para presença, contradizendo US-06/RF-11/RF-12. RESOLVIDO: idempotência vence — presença retorna 200 mesmo em corrida; 409 removido do RNF-13 para presença; US-06/RF-12 reescritos deixando claro que difere do 409 de `add_cell_member`.
- **P2** [APLICADO] [Incompatibilidade] "Central" tratado como papel distinto. RESOLVIDO: nota na Seção 0/Personas — no PR2 Central = `has_any_role(["pastor"])` + admin implícito, sem papel `lider_central` dedicado.
- **P3** [APLICADO] [Organização] RF-27 referenciava "US-14" inexistente. RESOLVIDO: trocado para US-08.
- **P4** [APLICADO] [Ambiguidades] Reunião sem horário. RESOLVIDO (opção a): materializar EXIGE `celulas.horario` → 422 se null (US-02); `hora` nullable só para legado/import documentado no RF-19; unicidade via `coalesce(hora,'')`.
- **P5** [APLICADO] [Ambiguidades] US-03 autorização de listagem. RESOLVIDO: qualquer autenticado do tenant lista (padrão de leitura de `cells.py`), sem guard de vínculo; escopo por `igreja_id` + 404. Título e critérios ajustados.
- **P6** [APLICADO] [Ambiguidades] Resolvedor de reunião. RESOLVIDO: novo RF-07b — `_get_reuniao_or_404` escopado por tenant (não-UUID → 404, fora do tenant → 404), sem exigir `cellId` no path.
- **P7** [APLICADO] [Lacunas] DEC-01 (modelo de PRESENÇA). RESOLVIDO = SPEC §8.2: `estado text` (`confirmada|compareceu|ausente`) + `origem`, não boolean. RF-21/US-05 e Seção 4 atualizados.
- **P8** [APLICADO] [Lacunas] DEC-02 (EXPECTATIVA). RESOLVIDO = SPEC §8.3: `nome_visitante NOT NULL` + `observacao_oracao`, não contagem. RF-22/RF-17/US-10 e Seção 4 atualizados.
- **P9** [APLICADO] [Excessos] Status da reunião. RESOLVIDO: mantidos os 4 valores no CHECK + nota de escopo no RF-19 declarando que transição de status fica fora do PR2 (só materialização em `planejada`).
